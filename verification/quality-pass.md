repository as exported, the thumbnails and the description, against the study, the sources and the channel's
standard. The reviewer is a Claude Opus session in a fresh context; a model of another family (OpenAI's gpt-6-luna)
reads the script as a second reader. Each pass ends `ready` or `not ready`; a finding is fixed before the next pass.
